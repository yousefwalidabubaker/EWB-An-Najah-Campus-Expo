04 / ABOUT

From a real expo to a frontend project.

EWB Campus Expo 2025 was held at An-Najah National University on 20 March 2025. I used the event as the idea for this small multi-page portal.

★ ✦ ★ ✦ ★
01

The idea

I wanted visitors to have one place to explore projects, check the day plan, and try a simple seat reservation flow.

02

The build

The project uses HTML, CSS, JavaScript, Vue 3, local storage, and GitHub Pages. I kept the structure simple and focused on frontend interaction.

03

The practice

I practiced Vue data, computed values, form handling, filtering, events, conditional rendering, responsive CSS, and saving basic data in the browser.

WHAT IS REAL?

The event and date are real.

The portal itself is a student project inspired by the expo. Booth names, reservation counts, and the detailed schedule are demo data used to make the website interactive.

This keeps the project useful as a frontend exercise without pretending that every piece of sample data came from the real event.
